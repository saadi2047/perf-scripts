5 · Saturation watch

  • NIC headroom. Busiest single node is infra2 at 160.4 Mbps peak — 1.6% of an assumed 10 Gbps link. Bandwidth is not a constraint in this window.
  • Conntrack. Peak 33,595 tracked connections on worker7. Compare against that node's limit (sysctl net.netfilter.nf_conntrack_max) — when entries approach the limit the kernel drops new connections and you see them as client-side timeouts, not as application errors.
  • Packet rate. Highest RX packet rate is 13,196 pkt/s on worker7. Well inside what a modern NIC handles; listed so a later run can be compared against it.
  • Counter reconciliation. Gateway 5,635,929 vs pods 5,599,860 — 0.64% apart. Under 1% is normal sampling skew between the two snapshot batches; above 3% means requests really were accepted and not served.
  • Internal fan-out. Each external request produces 3.43 request-hops inside the mesh. That multiplier is what turns a modest external rate into heavy sidecar CPU and connection churn — it is the number to watch if you reduce the external rate but CPU does not fall with it.
